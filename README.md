# RepoPilot

### Your AI-powered GitHub Repository Onboarding Assistant

RepoPilot is an autonomous AI agent that explores unfamiliar
GitHub repositories and generates:

- Repository onboarding guides.
- Architecture explanations and diagrams.
- File-by-file codebase explanations.
- First-contribution plans for developers.
